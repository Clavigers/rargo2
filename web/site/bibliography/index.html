Book Reference Protocol Bibliography
I considered naming this page prior art. Some of these references contain ideas I fully ripped off. Some explore the same problems in different ways. I started this project with the goal of replacing Bazel + BuildBuddy for my use cases. Despite that, I landed on a design that is fundamentally unlike Bazel. As a result, this “bibliography” is a bit all over the place.

  • sccache is pretty okay
  • Benchmarking Rust Compilation Speedups and Slowdowns from sccache I have used sccache, and I noticed for my own purposes that it was sometimes faster sometimes slower and sometimes flaky. I spent a weekend reading through the code path that gets touched when using sccache to cache Rust compilation with the local disk cache. My conclusion from this exercise was that sccache could be a lot better for Rust if it had been designed for Rust and not as a more general tool. I intend to write more about this.

  • The Next Generation of Bazel Builds The world has no shortage of Bazel haters. Guess what? I am not one of them! Bazel is very good. For a multi-language monorepo, there is no better tool. But if you can avoid it you should. Sticking to one language keeps complexity way down. My aspiration with Rargo is to bring the up-sides of Bazel to projects that decide to stick to Rust as their one language.
