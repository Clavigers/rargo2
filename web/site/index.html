1 Why (In 95 Words)

Warning! Rargo is in the middle of an in-progress rewrite. This site is under construction

Rargo is remote Cargo. You might want Rargo if you are facing slow or un­reliable builds.

Offload compi­lation to a build farm. Share a cache across a team. Se­lectively run tests affected by a change. Gain repro­ducibility without changing your code.

It’s a worn out trope, but Rargo fixes the “works on my ma­chine” problem. Rejoice, there is no mi­gration to do. Rargo is Cargo com­patible; you can always go back to building locally.

2 Getting Started

The rargo CLI is the official Rargo client. All cargo commands work with rargo.

cargo install rargo

To try Rargo, point your client at the public farm. To con­figure rargo to run builds on the public build farm, run this command:

The Farm is a Hetzner AX102 in Hel­sinki. It’s a nice ma­chine but it’s just one ma­chine. Please bear in mind, I pay for this out of pocket. If you queue a­lot of builds I might rate limit you.

rargo @rargo.rs

That will write your server to ~/.config/rargo/config.toml (under $XDG_CONFIG_HOME if you set it), beside the tokens rargo auth keeps. It is your setting, not the project’s: every Rust project on the machine builds there, fresh clones included, and no file in the project changes.

Alter­natively, you can set this environ­ment vari­able, which comes first:

export RARGO_SERVER=rargo.rs

Now, the rargo client knows which rargo server it should send actions requests to, but that it is not enough. The client must authenti­cate with the server before it can send requests.

rargo auth

The Farm lets in the people its owner has let in. rargo auth opens a page that asks you to prove you are one of them. If you need access, open a request on GitHub with your GitHub username. You can also skip the Farm: a server of your own is one command, and rargo @HOST puts it in the same user config file.

Once you are authenti­cated with the server, you can run any cargo command with rargo, the work will be done on the public farm and the result will be streamed back.

rargo buildrargo testrargo run -- --help

What the Farm builds links against the Farm’s own C library, from the Nix store. To run it on your machine, with rargo run or straight from target/, you need Nix installed. The first rargo run fetches the library into your store; after that the program runs either way.
